# CLAUDE.md — лендинг KIPCHACK

## Проект

Одностраничный адаптивный сайт школы метания ножей, стрельбы из лука и метания топоров **KIPCHACK** (Алматы).
Единственный источник правды по дизайну: макет `maket.png` (9 мобильных экранов). Всё, чего нет в макете, не добавлять без запроса.

## Стек

- Чистые HTML + CSS + JavaScript, без фреймворков, без сборщика, без npm-зависимостей.
- Файлы:
  ```
  index.html
  css/style.css
  js/main.js
  assets/img/   — изображения (webp/jpg)
  assets/icons/ — svg-иконки
  ```
- JS только там, где без него нельзя: бургер-меню, слайдеры, табы цен, плавный скролл.
- Сторонние библиотеки не подключать. Шрифты: Google Fonts.

## Главные правила

1. **Строго по макету.** Порядок секций, тексты, иерархия, отступы, скругления, цвета, иконки и кнопки как на макете. Не придумывать новые блоки, анимации и тексты. Если деталь на макете не читается, выбрать самый близкий вариант и упомянуть это в отчёте.
2. **DRY.** Повторяющееся оформляется один раз:
   - цвета, шрифты, отступы, радиусы, тени — только через CSS-переменные в `:root`;
   - карточки направлений, карточки форматов, карточки цен, кнопки, круглые кнопки-стрелки, заголовки секций — общие классы-компоненты с модификаторами, а не копии стилей;
   - один универсальный JS-слайдер для галереи и инструкторов, а не два отдельных.
3. **KISS.** Самое простое решение, которое работает. Без лишних обёрток, классов-«на будущее», абстракций и хитрых трюков. Семантичная вёрстка: `header`, `main`, `section`, `footer`, `nav`, `button`, `a`.
4. **Без лишних комментариев.** Код должен читаться сам. Комментарий допустим только там, где без него неочевидно *почему* так сделано. Никаких комментариев-разделителей и пересказа кода.
5. **Адаптивность под все ширины.** От 320px до 1920px+, без горизонтального скролла.
   - Mobile-first: базовые стили = макет (мобильная версия), дальше `min-width` медиазапросы.
   - Брейкпоинты: `576px`, `768px`, `1024px`, `1280px`.
   - Ширина контента ограничена контейнером (`max-width: 1200px`, боковые отступы 16–24px).
   - На планшете/десктопе карточки выстраиваются в сетку (2–3 колонки), hero и CTA в две колонки (текст + изображение), но стиль остаётся тем же, что на макете.
   - Размеры заголовков через `clamp()`.
   - Изображения: `max-width: 100%`, `object-fit: cover`, `loading="lazy"` для всего ниже первого экрана.

## Дизайн-токены

Значения сняты с макета на глаз; при наличии точных значений заменить только в `:root`.

```css
:root {
  --color-bg: #f2f2f2;
  --color-surface: #ffffff;
  --color-dark: #0d0d0d;
  --color-dark-surface: #1a1a1a;
  --color-text: #111111;
  --color-text-muted: #7a7a7a;
  --color-text-on-dark: #ffffff;
  --color-text-muted-on-dark: #9a9a9a;
  --color-border-on-dark: #2e2e2e;
  --color-accent: #b3261e;

  --font-display: "Russo One", sans-serif;
  --font-body: "Inter", sans-serif;

  --radius-card: 20px;
  --radius-pill: 999px;

  --container: 1200px;
  --gutter: 16px;
  --section-gap: clamp(64px, 10vw, 120px);
}
```

- **Палитра:** монохром (белый, светло-серый, чёрный) + один акцент — красный. Красный только для иконок преимуществ и финальной CTA-кнопки.
- **Заголовки:** жирный гротеск, ВЕРХНИЙ РЕГИСТР, плотный межстрочный интервал (~1.05).
- **Надзаголовки:** маленькие, серые, uppercase, увеличенный letter-spacing.
- **Основной текст:** мелкий, обычного начертания, серый/чёрный.
- **Кнопки:** pill-форма, чёрный фон, белый uppercase-текст, стрелка → справа. Финальная CTA — красная.
- **Кнопки-стрелки:** круглые, с тонкой обводкой (на тёмном фоне) или чёрные залитые (в карточках цен).
- **Карточки:** большие скругления; на тёмном фоне — тёмная заливка с тонкой обводкой; на светлом — белые.
- **Фото:** чёрно-белые/обесцвеченные, контрастные.
- Иконки — inline SVG или файлы в `assets/icons`, линейные, одной толщины.

## Качество

- Валидный HTML, у всех `img` есть `alt`, интерактивные элементы доступны с клавиатуры, у кнопок без текста есть `aria-label`.
- Никаких inline-стилей и `!important`.
- Именование классов единообразное (BEM: `card`, `card__title`, `card--dark`).
- Перед завершением проверить вёрстку на ширинах 320, 375, 768, 1024, 1440px.

## Отчёт после работы

После каждой задачи выдавать короткий отчёт на русском:

1. **Что сделано** — список изменений по секциям/файлам.
2. **Отклонения от макета** — что не удалось сделать один в один и почему.
3. **Допущения** — что пришлось додумать (нечитаемые детали, поведение на десктопе, значения токенов).
4. **Проверка** — на каких ширинах проверено, найденные проблемы.
5. **Что дальше** — что осталось сделать (например, заменить заглушки фото, карту, контакты).
